## 1. 확정된 UI/UX 사양 요약

| 영역 | 세부 개선 사양 |
|:---|:---|
| **뷰포트 제어** | `height: 100dvh; max-height: 100dvh; overflow: hidden;` (상하/좌우 스크롤 완전 차단) |
| **상단 네비바** | 1줄 고정 미니멀 헤더 (`러브레터` 텍스트 줄바꿈 해결, `TurnBanner` 1줄 인라인 핏, 32px 콤팩트 컨트롤 아이콘) |
| **상대방 영역 (상단 25%)** | 상대방 좌석 카드 (아바타 + VAD 링 + STT 말풍선 + 토큰/손패수 + **버린 패 오버랩 미니 스택**) |
| **중앙 테이블 (중앙 30%)** | 콤팩트 에메랄드 펠트 (남은 덱 수 💌 + 2인용 세트어사이드 공개 카드 + 1줄 최신 액션 칩) |
| **내 손패 영역 (하단 45%)** | 내 상태/버린패 요약바 + 모바일 맞춤 스케일 손패 1~2장 (부채꼴 틸트, 턴 골드 글로우, 백작부인 제약 가이드) |
| **버린 패(사용한 패) 스택** | 각 플레이어 앞/옆에 사용한 카드가 시간순으로 비스듬히 겹쳐 쌓임. 탭 시 전체 버린 카드 히스토리 팝오버 노출 |
| **카드 액션 모달** | 경비병/사제/남작/왕자/국왕 모달 모바일 최적화 (터치 타겟 44px 이상, 한 화면 팝업 핏) |

## 3. 상세 컴포넌트 구현 계획

### 3.1 `DiscardPileStack` 컴포넌트 (`LoveLetterBoard.jsx`)
- **시각화**: `discardPile` 배열을 받아 최대 최근 4~5장을 비스듬히 `-6px ~ +6px` 오프셋으로 겹쳐 렌더링.
- **상세 팝오버**: 스택을 터치하면 다이얼로그가 열리며 지금까지 해당 플레이어가 낸 모든 카드의 번호, 이름, 효과, 제출 순서를 한눈에 리스트업.

### 3.2 100dvh 무스크롤 레이아웃
- `BoardContainer`: `height: 100dvh; max-height: 100dvh; overflow: hidden; display: flex; flex-direction: column;`
- Flex 분할로 네비바(48px), 상대방(25%), 중앙(30%), 내손패(45% - 48px)를 정확히 비율 분배하여 어떤 모바일 기기에서도 스크롤바가 생기지 않도록 고정.

### 3.3 상단 네비바 최적화
- `TopNavBar`: `flex-shrink: 0; height: 48px; padding: 0 12px;`
- `GameTitle`: `white-space: nowrap; flex-shrink: 0;` (줄바꿈 방지)
- `TurnBanner`: 인라인 배너로 가로 폭 유동 조절, 텍스트 줄바꿈 방지(`white-space: nowrap; text-overflow: ellipsis;`)
