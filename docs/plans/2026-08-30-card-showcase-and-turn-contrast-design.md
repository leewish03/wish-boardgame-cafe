# Wish Boardgame Cafe: 실시간 카드 사용 쇼케이스 연출 및 턴 대비 극대화 시스템 설계서

> **확정 일자:** 2026-08-30
> **목표:** 
> 1. 상대방이 어떤 카드를 누구에게 사용했는지 화면 중앙에서 1.5초간 대형 카드로 직관적으로 보여주는 **실시간 카드 사용 쇼케이스(Card Play Showcase)** 구현
> 2. 내 턴(황금 스포트라이트, 손패 발광, 타이머 바)과 남의 턴(손패 딤드, 상대 좌석 펄스 조명, 대기 모드)의 **압도적인 시각적 대비(Visual Contrast)** 구축

## 1. 세부 기능 및 UX 연출 설계

### 1.1 실시간 카드 사용 쇼케이스 (Center Card Showcase)
- **발동 조건**: 나 또는 상대방이 카드를 낼 때 (`game:card-played` 또는 `lastActionLog` 브로드캐스트 시)
- **비주얼 연출**:
  - 화면 중앙에 **대형 카드(130px x 170px)** 가 0.2초 만에 스케일업(Spring 애니메이션)으로 등장
  - 카드 상단에 **`[{플레이어}] 님이 [{카드명}] 사용!`** 배지 및 타겟팅 안내(`🎯 -> [{대상}]`)
  - 카드 고유 색상(경비병 파랑, 사제 청록, 남작 보라, 하녀 초록, 왕자 주황, 국왕 골드, 백작부인 핑크, 공주 루비)의 네온 글로우 발광
  - 1.3초 후 부드럽게 페이드아웃되며 해당 플레이어의 버린 패 스택으로 날아가는 느낌 구현
  - 카드가 화면을 가리는 동안에도 게임 흐름을 방해하지 않도록 `pointer-events: none` 적용

### 1.2 내 턴 vs 남의 턴 극적 시각 대비 (Turn Visual Contrast)

| 상태 | 내 턴 (MY TURN) | 남의 턴 (OPPONENT'S TURN) |
|:---|:---|:---|
| **화면 배경 조명** | 하단 내 손패 영역에 **샴페인 골드 스포트라이트** 래디얼 그라디언트 발광 | 상단 활성 상대 좌석에 **앰버 펄스 조명** 집중, 하단은 캄(Calm) 다크 펠트 |
| **중앙 턴 배너** | **`👑 [내 턴] 카드를 선택하세요 (남은시간 25s)`** (골드 네온 펄스 애니메이션) | **`⏳ [서초스타일] 님의 턴 (생각 중... 18s)`** (차분한 다크 징크 배지) |
| **내 손패 비주얼** | **선명한 풀 컬러, 밝은 테두리, 미세 호버/선택 팝업, 낼 수 있는 상태** | **손패 40% 딤드(어두움), 흑백 채도 감소(Grayscale 30%), 터치 비활성화** |
| **상대방 좌석 비주얼**| 상대방 좌석은 기본 대기 상태 | **현재 턴인 상대방 좌석 전체가 골드 네온 테두리 + 아바타 펄스 회전 링 + `⏳ 생각 중...` 배지** |
| **사운드 & 진동** | 턴 시작 시 경쾌한 턴 알림음 (`sfx.playTurnAlert()`) + 모바일 미세 진동 (`navigator.vibrate(50)`) | 상대방 카드 제출 시 타격음만 재생 |
