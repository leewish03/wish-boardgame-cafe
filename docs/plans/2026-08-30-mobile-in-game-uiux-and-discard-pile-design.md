## 1. 확정된 UX/UI 세부 사양표

| 기능 / 영역 | 확정된 사양 | 사용자 편의성(UX) 효과 |
|:---|:---|:---|
| **화면 제어** | `height: 100dvh; max-height: 100dvh; overflow: hidden;` | 모바일 어떤 기기에서도 위아래 스크롤 100% 방지 |
| **상단 네비바** | 48px 1줄 고정 헤더 (`러브레터` 줄바꿈 차단, 1줄 인라인 턴 배너, 32px 콤팩트 제어 버튼) | 헤더가 화면을 가리지 않고 필수 컨트롤 즉시 접근 |
| **카드 제출 방식** | **2단계 안전 터치** (카드 탭 시 위로 슬라이드 팝 선택 → 하단 `[카드 사용]` 버튼 클릭 시 발동) | 모바일 엄지손가락 오터치 및 실수 제출 완벽 방지 |
| **상대 지목 방식** | **테이블 직접 터치 타겟팅** (타겟팅 모드 진입 시 상대 좌석이 골드로 펄스 발광하며 직접 탭하여 지목) | 직관적인 보드게임 손맛 및 조작 동선 최소화 |
| **보호 상태 가드** | 하녀(4) 보호(🌸) 중인 상대는 타겟팅 시 자동 딤드 비활성화 및 안내 | 규칙 위반 시도 원천 차단 |
| **사용한 패 (Discard Pile)** | 각 플레이어(상대 및 나) 앞/옆에 낸 카드가 시간순으로 비스듬히 겹쳐 쌓임 + 탭 시 전체 목록 팝오버 | 게임 중 누가 무슨 카드를 냈는지 한눈에 파악 |
| **경비병 스마트 추측** | 2~8번 버튼 위에 현재 테이블에 안 나온 **'남은 카드 수(예: 사제 남은 1/2장)'** 자동 표시 (0장은 비활성화) | 모바일에서 카드 암기 스트레스 제거 및 직관적 추리 |
| **백작부인 제약 가이드** | 손에 왕자(5)나 국왕(6)과 백작부인(7)이 함께 있을 때, 왕자/국왕은 딤드 처리 및 "백작부인 필수 사용" 배지 노출 | 룰 실수 방지 |
| **특수 모달 연출** | 스내피(Snappy) 퀵 모달 (사제 손패 확인, 남작 결투 등 0.3초 내 깔끔 팝업 & 확인 시 즉시 닫힘) | 모바일 플레이 템포 극대화 |
| **라운드 종료 연출** | 승자 토큰 수여 + 전원 최종 손패 공개 + `[다음 라운드]` 원클릭 즉시 시작 | 지루한 대기 시간 없는 경쾌한 회전율 |

## 3. 상세 컴포넌트 구현 명세

### 3.1 `DiscardPileStack` 및 `DiscardHistoryModal`
- 각 플레이어의 `p.discardPile` (예: `[{ name: '경비병', value: 1 }, { name: '남작', value: 3 }]`)을 순회.
- 미니 카드 칩을 `-8px` 가로 오프셋으로 비스듬히 겹쳐 렌더링.
- 탭하면 `DiscardHistoryModal`이 열려 지금까지 낸 카드의 순서, 효과, 아이콘을 전체 리스트업.

### 3.2 테이블 직접 터치 타겟팅 시스템
- `targetingCard`: 현재 플레이어가 사용하려는 카드 (예: 경비병, 사제, 남작, 왕자, 국왕).
- `targetingState`: `'SELECTING_PLAYER' | 'GUESSING_CARD' | null`.
- `targetablePlayers`:
  - 기본적으로 `!p.isEliminated && !p.isProtected && p.id !== myId`.
  - 왕자(5)의 경우 `p.id === myId` (자신도 선택 가능).
- 타겟팅 모드 시 상대 좌석에 골드 펄스 애니메이션 + `🎯 지목하기` 배지 표시.
- 상대 좌석을 터치하면:
  - 경비병(1): `targetingState = 'GUESSING_CARD'`로 전환되며 스마트 2~8 추측 그리드 팝업.
  - 사제/남작/왕자/국왕: 즉시 `executePlayCard` 소켓 이벤트 발송.
- 취소 버튼(`[✕ 선택 취소]`)을 항상 하단에 제공.

### 3.3 스마트 경비병 추측 그리드 (Card Counter Helper)
- 현재 테이블에 공개된 모든 카드(전체 플레이어 discardPile + 2인전 오픈 제외 카드 + 내 손패)를 집계하여 `revealedCounts[value]` 계산.
- 카드별 전체 매수:
  - 1번(5장), 2번(2장), 3번(2장), 4번(2장), 5번(2장), 6번(1장), 7번(1장), 8번(1장) (5~6인전은 덱 확장치 반영).
- 2~8번 버튼 렌더링 시: `남은 추정 매수 = 전체 매수 - 공개된 매수`.
  - 남은 수가 0장인 카드는 비활성화(`disabled`) 및 "0장 남음" 표시.
  - 남은 수가 있는 카드는 골드/선명한 색상으로 활성화.
