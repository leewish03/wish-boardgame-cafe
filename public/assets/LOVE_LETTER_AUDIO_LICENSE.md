# Love Letter salon music

`love-letter-salon-loop.mp3` is **JRPG2 Piano** by Joth, downloaded from
https://opengameart.org/content/jrpg2-piano on 2026-09-01.

The source page designates the work **CC0 / public domain**. Attribution is not
required; this record is retained so the shipped asset can be audited.

The application loops the file at a restrained default volume of 15% after the
player's first table interaction.
